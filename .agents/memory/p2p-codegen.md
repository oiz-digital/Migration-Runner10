---
name: P2P codegen dependency
description: P2P frontend page requires generated React Query hooks that must be regenerated after OpenAPI spec changes
---
P2P.tsx imports hooks like `useListP2pOffers`, `useOpenP2pOrder` etc. from `@workspace/api-client-react`.
These are generated by Orval from `lib/api-spec/openapi.yaml`.

Fix when hooks are missing:
1. `pnpm --filter @workspace/api-spec run codegen`
2. `pnpm run typecheck:libs`
3. Restart user-portal workflow

**Why:** P2P routes exist in openapi.yaml but codegen output was stale/missing.
